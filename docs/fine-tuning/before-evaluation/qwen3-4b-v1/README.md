Prior reports remain historical; see [the owner decision](../../design/06-owner-selected-qwen3-baseline.md).

The frozen 404 remains `b6a6a9f74e76edcf783ad3a2f47f2fa493ac0444e2ca8bf239439229e14a2b05`, 101 rows per language. Its expected answers are unchanged. It is not used to select the model or tune prompts/settings. The S-160 asset is not executed or used as model input here.

[baseline-lock.json](baseline-lock.json) was sealed before the first F case, followed by [55 passing preflight checks](preflight-final.json), six passing JS syntax checks and zero preflight live model calls/F executions. The explicit official invocation uses one sequential pass and a single-use [execution marker](results/execution-started.json). There are no automatic retries, restarts, provider fallbacks or case exclusions. Isolation/model/source drift stops the run; an incomplete run is preserved rather than overwritten.

The existing source formatter, schema, resolver, role registries and HTTP orchestration run unchanged in a restricted child/VM. Only the admitted R-v1.1 hash `f66937264beeb823ea5106aa7689deb18fd50963e9df9312dd772c3ee5f56736` supplies typed runtime references. The original training loader/10K/build copies and unadmitted phrasebook/conversation/help arrays are excluded. Empty help/page/retention/memory boundaries and synthetic directory/read fixtures are explicit evaluation overrides, not production changes. Actual protected execution is intercepted. Source and override hashes are locked for reproducibility.

Production DB/MCP/RAG/auth/credentials and business writes are blocked. A declared synthetic knowledge fixture is not real RAG. Native permissions prohibit writes/processes and unapproved reads; source import graphs and transport are allowlisted, and violations remain latched. The only model endpoint is `http://127.0.0.1:11434/api/chat`; version/tags are read-only identity checks. Headers carry no credentials, redirects are rejected, and digest/version are rechecked throughout. No cloud model is configured. OpenAI action/continuation/prose calls stay unconfigured; those stages can therefore be unavailable. Missing fixture services are not replaced with production access or invented success.

Installed Modelfile defaults are temperature .6, top_p .95, top_k 20, repeat penalty 1 and the recorded stop/template values. Evaluation explicitly uses the already predeclared Phase 1D.0 settings: temperature 0, top_p 1, seed 42, 512 generated-token cap, context 8192, eight CPU threads, batch 128, GPU layers 0, keep_alive 30m; `think:false`, existing Qwen3 `/no_think`, JSON Schema `format`, `stream:false`, existing Zod/semantic validation, 120s request/full-body and 150s parent bound. No benchmark warm-up occurs: the first model request's cold-load cost remains scored. No settings or source changes are allowed after results begin.

The unchanged historical F scorer measures intent, action, **annotated input entity/parameter keys**, clarification, confirmation and scope/behavior observations. It does not have full unannotated-plan golds; **strict full-plan accuracy is unavailable**, never fabricated. Supplemental all-annotation exactness is explicitly named and requires every applicable frozen annotation plus observed clarification/confirmation/scope/behavior, no error and no unsafe flags. Fixture/unconfigured gaps fail that supplementary conjunction but remain distinct from model prediction errors. Service-boundary supplied candidates are not language-model predictions; local-boundary abstentions are separate component checks. Publish both scorable-only and attempt-wide denominators.

Provider raw bodies and structured model content, HTTP/error codes, validation observations, token counts and available load/prompt/evaluation durations are retained. Request bodies are represented by hashes/byte sizes rather than copied F prompts. Per-case observations and scores are append-only and fsynced. Child/request latency uses `performance.now()`, never wall-clock subtraction; timeout/invalid durations are bounded. Non-streaming TTFT is unavailable. Provider timeout events remain visible even where the existing resolver maps them to `aiUnavailable`.

Raw/aggregate files appear as the run proceeds or completes; existence of a start marker is not a completion claim. The authoritative finished/incomplete state is [aggregate-metrics.json](results/aggregate-metrics.json). [Result hashes](results/result-hashes.sha256) are produced only when the run finalizes. Do not reexecute the runner to recover an incomplete run without a separately approved protocol; never delete the marker or overwrite raw outputs.

Human review was not performed and is not required under the controlled automated-admission amendment. Arabic/English naturalness is not independently human validated. All experimental reports/publication must disclose that limitation and this controlled profile's service/action/guide coverage limits. Owner-requested aggregate disclosure is allowed; do not use F raw failures for prompt/rule/settings changes or training. Nothing is published.

No fine-tuning or training export is authorized or started. A pinned inference GGUF does not establish its original trainable-checkpoint/adaptation/export provenance.
