# Independent replacement dataset-v2

This release uses a new, independently authored contract-driven synthetic recipe. It does not reuse dataset-v1 requests, targets, templates, lexicons, or protected-corpus matching selectors. Only the approved contract catalog and fresh generation modules are readable in the native-permission generation child. Secrets and excluded datasets have denied-read canaries. No model or external teacher is called.

Before protected comparisons, the recipe and validators are hashed in `generation/pre-generation-manifest.json`. Candidate-only authoring checks are retained, including failed drafts. The initial candidate-only issues were repeated masked continuation constructions and an ordinary English action frame triggering the existing bank-pattern scanner. These were corrected before protected comparisons; no checker, privacy pattern, threshold, or protected example guided those corrections.

The four original admission checkers are byte-identical to the quarantined release. Contamination still requires zero exact, normalized, entity-masked or strong-near matches, with the original token-shingle, character-shingle and edit-similarity thresholds. A separate sealed comparison also excludes the previous quarantined release using those same predicates. Only aggregate counts leave sealed checks. Protected benchmark rows and match identifiers are never provided to generation. After protected checks, this release cannot be rewritten or repaired against their feedback.

Exactly 2,000 construction families contain four language renditions each. Each language has 1,600 train / 200 dev / 200 internal-test examples. Families and construction groups stay in one split; split-specific syntax and entity pools are used. All 32 question intents and 48 question-stage action-boundary categories are covered. `doAction` is classification only; confirmation, permissions, factual HR answers and action execution are not training targets.

The canonical supervised mapping is natural HR request plus trusted synthetic role/context to the existing `{plan: CopilotPlan}`. Prompt-completion exports, if admitted, use the unchanged shared formatter and previously approved synthetic runtime references as prompt context only; these are not new requests or gold targets. No new prompt instructions or model settings are introduced.

Limitations: templates and translations have not undergone independent human linguistic review; placeholder-only entities do not demonstrate natural-name extraction; static privacy and lexical checks are not a complete semantic or PII certification. The exact BEFORE GGUF conversion link remains an owner-accepted provenance limitation. Pinned tokenizer/loss-mask qualification and training-runtime preparation remain separate pre-training gates. No training starts as part of generation or admission.
